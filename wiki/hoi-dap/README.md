# hoi-dap/

Mỗi file ở đây tương ứng với **một nguồn** đã ingest từ `raw/ghi-chu-ca-nhan/` (hoặc `raw/bai-giang/`, `raw/bai-viet/`) — tóm tắt câu hỏi đã hỏi thầy Long và ý chính trong câu trả lời. Đặt tên trùng ngày/chủ đề với file nguồn, ví dụ `2026-03-14-hoi-ve-dong-tien.md`.

Đây là lớp "tóm tắt theo từng nguồn". Ý được rút ra từ đây sẽ được đẩy tiếp lên các trang tổng hợp hơn trong `../chu-de/` và `../khai-niem/`. Luôn có frontmatter `nguon:` trỏ về file gốc trong `raw/`.
