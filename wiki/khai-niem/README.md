# khai-niem/

Mỗi file ở đây là một khái niệm, mô hình, hoặc thuật ngữ cụ thể mà thầy Long hay dùng (ví dụ một "công thức" tư duy, một mô hình ra quyết định có tên riêng). Chỉ tạo trang riêng khi khái niệm đủ quan trọng và được nhắc lại nhiều lần — nếu chỉ xuất hiện một lần, để trong trang `hoi-dap/` hoặc `chu-de/` tương ứng là đủ.

Luôn link ngược lại các trang `chu-de/` hoặc `hoi-dap/` nơi khái niệm được nhắc đến.
